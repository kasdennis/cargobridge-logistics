
# CargoBridge Logistics

## Project Overview

CargoBridge Logistics is a web-based cargo import and export management platform.

The platform will help logistics companies manage customers, cargo requests, quotations, shipments, invoices, and shipment tracking.

## Project Objectives

- Provide a professional company website.
- Allow customers to submit cargo requests.
- Manage import and export shipments.
- Generate unique shipment tracking numbers.
- Provide shipment tracking information.
- Manage quotations and invoices.
- Provide an administrative dashboard.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- TypeScript
- React
- Next.js
- Tailwind CSS
- Supabase
- PostgreSQL
- Git and GitHub
